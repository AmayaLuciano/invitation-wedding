# Invitation Wedding

Invitación digital de Isabella y Luciano.

Proyecto basado en la estética del sitio original, simplificado para funcionar únicamente como invitación: información del evento, cronograma, ubicación, vestimenta y cuenta regresiva.

No utiliza RSVP, regalos, Supabase ni base de datos.

## Desarrollo

```bash
npm install
npm run dev
```

## Producción

```bash
npm run build
npm start
```
